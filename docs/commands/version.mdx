# vibium version

Print the version number.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths and ids will differ on your machine.
:::

## Synopsis

```
vibium version
vibium --version
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Output

Both forms print the same string:

```sh
$ vibium version
vibium v26.8.21

$ vibium --version
vibium v26.8.21
```

:::warning[`--json` is ignored on this version]
Output is identical with and without the flag. This is the family of gaps
reported upstream as
[#451](https://github.com/VibiumDev/vibium/issues/451); several members were
fixed after this release.
:::

```sh
$ vibium version --json
vibium v26.8.21
```

Not an envelope — parse the plain string, or read the daemon's version from
[`vibium daemon status`](/docs/commands/daemon), which reports it too.
