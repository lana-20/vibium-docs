# vibium paths

Print the browser and cache paths vibium uses.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths and ids will differ on your machine.
:::

## Synopsis

```
vibium paths
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Output

```sh
$ vibium paths
Cache directory: /Users/lanabegunova/Library/Caches/vibium
Chrome: /Users/lanabegunova/Library/Caches/vibium/chrome-for-testing/152.0.7977.54/Google Chrome for Testing.app/Contents/MacOS/Google Chrome for Testing
Chromedriver: /Users/lanabegunova/Library/Caches/vibium/chrome-for-testing/152.0.7977.54/chromedriver
```

The first stop when a launch fails: it shows exactly which binary vibium will
run, including the version directory, so a stale or partial download is visible
immediately.

Paths follow `--engine`, so `vibium --engine firefox paths` reports the Firefox
locations instead.

:::warning[`--json` is ignored on this version]
Output is identical with and without the flag. This is the family of gaps
reported upstream as
[#451](https://github.com/VibiumDev/vibium/issues/451); several members were
fixed after this release.
:::
