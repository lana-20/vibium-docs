# vibium pdf

## Synopsis

```
vibium pdf [url]
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--output`, `-o` | `string` | Output file path (default "page.pdf") |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Examples

```sh

# Save current page as PDF

# Navigate to URL first, then save as PDF
```
