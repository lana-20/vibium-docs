# vibium media

Override CSS media features.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium media [--color-scheme dark|light] [--reduced-motion ...] [...]
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--color-scheme` | `string` | `light` or `dark` |
| `--reduced-motion` | `string` | `reduce` or `no-preference` |
| `--forced-colors` | `string` | `active` or `none` |
| `--contrast` | `string` | contrast preference |
| `--media` | `string` | media type, e.g. `print` |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Emulating dark mode

The command names the features it applied, and the page sees the change
immediately:

```sh
$ vibium media --color-scheme dark
Media emulation applied: [colorScheme]

$ vibium eval "matchMedia('(prefers-color-scheme: dark)').matches"
true
```

`--media print` is the way to preview print styles before
[`vibium pdf`](/docs/commands/pdf), which applies them anyway.

Overrides persist for the session. Set the feature back explicitly to undo it —
there is no reset:

```sh
vibium media --color-scheme light
```
