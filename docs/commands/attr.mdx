# vibium attr

Get an HTML attribute value from an element.

:::info[Generated reference]

## Synopsis

```
vibium attr [selector] [attribute]
```

## Examples

```sh
vibium attr "a" "href"
# Get the href of the first link

vibium attr "img" "src"
# Get the image source URL
```
