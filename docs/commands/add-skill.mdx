# vibium add-skill

Install the vibium browser skill for Claude Code.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths, ports and ids will differ on your machine.
:::

## Synopsis

```
vibium add-skill
vibium add-skill --stdout
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--stdout` | — | Print the skill content instead of installing it |

Global flags apply as well — see [Global flags](/docs/global-flags).

## What it installs

A bare `add-skill` writes a skill to `~/.claude/skills/vibe-check/`, giving
Claude Code the command reference it needs to drive vibium.

:::warning[It overwrites an existing skill without asking]
There is no prompt, no backup and no `--dry-run`. If you have customised
`~/.claude/skills/vibe-check/`, your changes are lost.

Inspect first with `--stdout`, which prints the skill and installs nothing:

```sh
$ vibium add-skill --stdout | head -4
---
name: vibe-check
description: Browser automation for AI agents. Use when the user needs to navigate websites, read page content, fill forms, click elements, take screenshots, or manage browser pages.
---
```

The skill is 394 lines at this version. Diff it against what you have before
overwriting:

```sh
vibium add-skill --stdout | diff ~/.claude/skills/vibe-check/SKILL.md -
```
:::
