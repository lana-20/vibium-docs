# vibium window

Get or set the OS browser window.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium window
vibium window <width> <height> [x] [y]
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--state` | `string` | normal, minimized, maximized, fullscreen |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Reading

```sh
$ vibium window
{"state":"normal","x":22,"y":22,"width":756,"height":556}
```

This is the operating-system window, including browser chrome — which is why
its height exceeds the [`viewport`](/docs/commands/viewport)'s 469 by the
toolbar's worth of pixels.

Setting the window resizes the viewport as a side effect, but not to the same
numbers. If what you need is a specific *page* size — for a screenshot, or to
reproduce a layout bug — set the
[`viewport`](/docs/commands/viewport) directly instead.
