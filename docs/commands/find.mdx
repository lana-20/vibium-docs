# vibium find

Find elements by CSS selector or semantic locator.

:::info[Generated reference]
Derived from `vibium help find` at **vibium v26.8.21**. The examples below are the
command's own built-in samples, not captured terminal output. Pages marked
*Verified* instead carry output from a live browser run.
:::

## Synopsis

```
vibium find [selector]
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--all` | — | Find all matching elements |
| `--limit` | `int` | Maximum number of elements to return (with --all) (default 10) |
| `--timeout` | `timeout` | Max time to wait, e.g. 5s or 5000 (bare number = milliseconds) (default 30s) |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Examples

```sh
vibium find "a"
# → @e1 [a] "More information..."

vibium find "a" --all
# → @e1 [a] "Home"  @e2 [a] "About"  ...

vibium find text "Sign In"
# → @e1 [button] "Sign In"

vibium find role button
# → @e1 [button] "Submit"

vibium find role heading --name "Example"
# Find heading with accessible name "Example"
```
