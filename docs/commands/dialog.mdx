# vibium dialog

Accept or dismiss a JavaScript dialog.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium dialog accept [text]
vibium dialog dismiss
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## The click that opens a dialog appears to fail

:::danger[Read this before anything else on this page]
A JavaScript dialog blocks the page, so the command that triggered it cannot get
a response. [`click`](/docs/commands/click) therefore **times out and exits 1**
even though the click worked and the dialog is open:

```sh
$ vibium click "#alert-btn"
Error: read response: read unix ->/Users/…/vibium.sock: i/o timeout
$ echo $?
1

$ vibium dialog accept
Dialog accepted
```

The `dialog accept` succeeds, which proves the click had opened it. Reproducible
on every run.

So a click that opens a dialog must be treated as expected-to-fail: ignore its
exit status, and assert on the dialog instead.
:::

## Confirm and prompt

`accept` and `dismiss` map onto the two answers, and the fixture records which
it received:

```sh
$ vibium dialog accept
Dialog accepted
$ vibium text "#status"
Confirmed

$ vibium dialog dismiss
Dialog dismissed
$ vibium text "#status"
Dismissed
```

For a `prompt`, pass the reply as an argument to `accept`:

```sh
$ vibium dialog accept "Lana"
Dialog accepted with text: "Lana"

$ vibium text "#status"
Prompt: Lana
```

## When no dialog is open

```sh
$ vibium dialog accept
Error: failed to accept dialog: BiDi error: no such alert - no such alert
$ echo $?
1
```

There is no command to test whether a dialog is open, so this error is also the
way to find out — which makes the exit status ambiguous between "no dialog" and
"something else went wrong".
