# vibium uncheck

Untick a checkbox, if it is currently ticked.

## Synopsis

```
vibium uncheck <selector>
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--timeout` | `timeout` | Max time to wait (default 30s) |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Idempotent, like `check`

```sh
$ vibium check "#terms"
Checked #terms

$ vibium uncheck "#terms"
Unchecked #terms

$ vibium is checked "#terms"
false

$ vibium uncheck "#terms"
Already unchecked: #terms

$ vibium is checked "#terms"
false
```

Running it twice is safe: the second call reports `Already unchecked` and leaves
the box alone, where a second [`click`](/docs/commands/click) would tick it
again.
