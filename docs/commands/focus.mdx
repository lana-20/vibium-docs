# vibium focus

Give an element keyboard focus, without clicking it.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium focus <selector>
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Focusing

```sh
$ PLAYGROUND=https://lana-20.github.io/vibium-docs/fixtures/playground.html
$ vibium go "$PLAYGROUND"
Navigated to https://lana-20.github.io/vibium-docs/fixtures/playground.html

$ vibium focus "#email"
Focused element: #email

$ vibium eval "document.activeElement.id"
email
```

:::tip[`focus` does not move the caret; `type` and `press` do]
[`type`](/docs/commands/type) and [`press`](/docs/commands/press) reach a field
by *clicking* it, which places the caret wherever the click lands — often in the
middle of existing text. `focus` uses the DOM method instead, leaving the caret
at the end.

So to append a keystroke without disturbing the value, focus first and use the
no-selector form of [`keys`](/docs/commands/keys):

```sh
$ vibium focus "#email"
Focused element: #email

$ vibium keys "Enter"
Pressed keys: Enter
```
:::

## JSON output

```sh
$ vibium focus "#email" --json
{"ok":true,"result":"Focused element: #email"}
```
