# vibium hover

Move the pointer over an element.

## Synopsis

```
vibium hover <selector>
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--timeout` | `timeout` | Max time to wait, e.g. `5s` or `5000` (a bare number is milliseconds; default 30s) |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Hovering

The fixture reports its own hover state, so the effect is observable:

```sh
$ PLAYGROUND=https://lana-20.github.io/vibium-docs/fixtures/playground.html
$ vibium go "$PLAYGROUND"
Navigated to https://lana-20.github.io/vibium-docs/fixtures/playground.html

$ vibium text "#hover-status"
out

$ vibium hover "#hover-target"
Hovered over element: #hover-target

$ vibium text "#hover-status"
in
```

The pointer stays where `hover` left it, so a later
[`click`](/docs/commands/click) elsewhere moves it away and fires `mouseleave`.
Assert on the hover-dependent state before doing anything else.

## JSON output

```sh
$ vibium hover "#hover-target" --json
{"ok":true,"result":"Hovered over element: #hover-target"}
```
