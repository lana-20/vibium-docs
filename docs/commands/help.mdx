# vibium help

Show help for vibium or one of its commands.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths and ids will differ on your machine.
:::

## Synopsis

```
vibium help [command]
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Use this instead of `--help`

:::tip[`vibium help <cmd>` works where `<cmd> --help` does not]
Four commands — [`fill`](/docs/commands/fill), [`type`](/docs/commands/type),
[`geolocation`](/docs/commands/geolocation) and
[`sleep`](/docs/commands/sleep) — disable flag parsing and read `--help` as a
missing argument:

```sh
$ vibium fill --help
Error: accepts 2 arg(s), received 0
```

`help` takes a different path and works for every command:

```sh
$ vibium help fill
Clear an input field and type new text

Usage:
  vibium fill [selector] [text] [flags]
```

Because of this, the generator behind this site reads `vibium help <cmd>` rather
than `<cmd> --help`. Reported upstream as
[#422](https://github.com/VibiumDev/vibium/issues/422) and
[#423](https://github.com/VibiumDev/vibium/issues/423), fixed after this
release.
:::

## Listing everything

`vibium help` with no argument prints the root help, the authoritative list of
all 67 commands:

```sh
$ vibium help
Browser automation for AI agents and humans

Usage:
  vibium [flags]
```

Subcommands take a path: `vibium help find role`, `vibium help record start`.
