# vibium upload

Set files on a file input.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium upload <selector> <file...>
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Setting a file

```sh
$ PLAYGROUND=https://lana-20.github.io/vibium-docs/fixtures/playground.html
$ vibium go "$PLAYGROUND"
Navigated to https://lana-20.github.io/vibium-docs/fixtures/playground.html

$ vibium upload "#file-input" /tmp/up.txt
Set 1 file(s) on #file-input

$ vibium eval "document.querySelector('#file-input').files[0].name"
up.txt

$ vibium eval "document.querySelector('#file-input').files[0].size"
15
```

:::note[`value` is not useful on a file input]
Browsers report a file input's value as `C:\fakepath\<name>` for privacy, so
[`vibium value`](/docs/commands/value) tells you almost nothing. Read
`files[0].name` through [`eval`](/docs/commands/eval), as above.
:::

## A missing file is not an error

:::danger[A wrong path uploads an empty file, and reports success]
`upload` does not check that the path exists. Given one that does not, it still
reports success, exits 0, and attaches a **zero-byte** file named after the path
you gave:

```sh
$ ls /tmp/nope.txt
ls: /tmp/nope.txt: No such file or directory

$ vibium upload "#file-input" /tmp/nope.txt
Set 1 file(s) on #file-input
$ echo $?
0

$ vibium eval "document.querySelector('#file-input').files.length"
1
$ vibium eval "document.querySelector('#file-input').files[0].name"
nope.txt
$ vibium eval "document.querySelector('#file-input').files[0].size"
0
```

A typo in the path therefore submits an empty attachment rather than failing.
Check the file exists before calling `upload`, or assert on `files[0].size`
afterwards.
:::
