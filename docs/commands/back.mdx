# vibium back

Navigate the active page to the previous entry in session history.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium v26.8.21**,
not transcribed help text.
:::

## Synopsis

```
vibium back
```

## Description

Equivalent to clicking the browser's back button. The command prints
`Navigated back` once the navigation has committed.

`back` never fails: at the start of history it simply stays where it is and
still reports success. Note that the browser's own startup entries sit before
your first [`vibium go`](/docs/commands/go), so stepping back far enough lands on a blank
page rather than an error.

Element references from [`vibium map`](/docs/commands/map) do not survive a navigation —
re-map the page after going back.

## Examples

```sh
$ vibium go https://example.com
Navigated to https://example.com

$ vibium go https://example.com/index.html
Navigated to https://example.com/index.html

$ vibium back
Navigated back

$ vibium url
https://example.com/
```
