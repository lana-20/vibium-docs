# vibium html

Read markup, from the whole document or one element.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium html [url] [selector]
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--outer` | — | Return outerHTML instead of innerHTML |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Inner and outer

The default is `innerHTML` — the element's *contents*, without the element
itself. `--outer` includes the element's own tag:

```sh
$ PLAYGROUND=https://lana-20.github.io/vibium-docs/fixtures/playground.html
$ vibium go "$PLAYGROUND"
Navigated to https://lana-20.github.io/vibium-docs/fixtures/playground.html

$ vibium html "nav"

    <a href="#home">Home</a>
    <a href="#docs">Docs</a>
    <a href="#about">About</a>
  

$ vibium html "nav" --outer
<nav>
    <a href="#home">Home</a>
    <a href="#docs">Docs</a>
    <a href="#about">About</a>
  </nav>
```

Note the leading and trailing whitespace in the `innerHTML` form — it is the
markup's own indentation, returned verbatim. Trim before comparing.

## The whole document

With no selector, `html` returns the serialised document as the browser holds
it now, not the bytes the server sent:

```sh
$ vibium html | head -3
<html lang="en"><head>
<meta charset="utf-8">
<title>Vibium docs playground</title>
```

The parser has already normalised it, so expect `<head>` to be present even if
the source omitted it, and any DOM changes made since load to be included.

## When the element is missing

```sh
$ vibium html ".nope"
Error: failed to get HTML: element not found
$ echo $?
1
```

## JSON output

```sh
$ vibium html "h1" --json
{"ok":true,"result":"Playground"}
```
