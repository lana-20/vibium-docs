# vibium serve

Run a WebSocket proxy in front of the browser.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths, ports and ids will differ on your machine.
:::

## Synopsis

```
vibium serve
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--port` | `int` | Port to listen on (default 9515) |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Running

```sh
$ vibium serve
Starting Vibium proxy server on port 9515...
Server listening on ws://localhost:9515
Press Ctrl+C to stop...
```

Clients then connect to `ws://localhost:9515` — including vibium itself, via
[`vibium start <ws-url>`](/docs/commands/start), which is how you drive a
browser on another host.

:::warning[This command does not exit on its own]
It runs until interrupted, printing `Press Ctrl+C to stop...`. Do not call it
from a script that waits for completion — it will hang. Run it in the
background, or bound it explicitly (macOS has no `timeout(1)`).
:::
