# vibium is-installed

Test whether the selected browser is installed.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths and ids will differ on your machine.
:::

## Synopsis

```
vibium is-installed
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## The answer is the exit code

:::warning[This command prints nothing at all]
There is no output on either path. The result is *only* the exit status:

```sh
$ vibium is-installed
$ echo $?
0
```

`0` means installed, `1` means not. That makes it the rare vibium command that
is genuinely safe in a conditional, unlike [`vibium is`](/docs/commands/is),
which always exits 0:

```sh
vibium is-installed || vibium install
```

`--json` produces no output either, so there is nothing to parse in any mode —
still true on current `main` as of 2026-09-01.
:::

## Per engine

The check follows `--engine`:

```sh
vibium --engine firefox is-installed
```
