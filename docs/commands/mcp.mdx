# vibium mcp

Run vibium as an MCP server over stdio.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths, ports and ids will differ on your machine. The home directory is shown as `~` in place of the absolute path it was captured with; output is otherwise verbatim.
:::

## Synopsis

```
vibium mcp
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Running

The server speaks JSON-RPC on stdin/stdout, so it is started *by* an MCP client
rather than by you:

```sh
$ vibium mcp
Vibium MCP server v26.8.21
This server communicates via JSON-RPC over stdin/stdout.
It's meant to be run by an MCP client (e.g., Claude Desktop).

Chrome: ~/Library/Caches/vibium/chrome-for-testing/152.0.7977.54/Google Chrome for Testing.app/Contents/MacOS/Google Chrome for Testing
```

It then waits on stdin. Running it in a terminal is only useful to confirm it
starts and to see which browser it resolved.

## Known issue: `mcp` redeclares `--headless`

:::warning[`--headless` behaves differently here on this version]
`mcp` declares its own `--headless` flag, shadowing the root's persistent one.
It shows under **Flags:** rather than **Global Flags:** in `vibium help mcp`,
with a different description. Reported upstream as
[#452](https://github.com/VibiumDev/vibium/issues/452) and fixed after this
release.
:::
