# vibium stop

Close the browser session.

## Synopsis

```
vibium stop
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Stopping

```sh
$ vibium stop
Browser session closed
```

Idempotent — a second call is not an error:

```sh
$ vibium stop
No browser session to close
$ echo $?
0
```

## `stop` also stops the daemon

:::warning[This is heavier than "close the browser"]
The daemon goes with it, which is easy to miss:

```sh
$ vibium daemon status
vibium daemon v26.8.21
status:   running
pid:      23998

$ vibium stop
Browser session closed

$ vibium daemon status
Daemon is not running.
$ echo $?
1
```

The next command therefore pays the full daemon-plus-browser startup cost, not
just a browser launch. In a loop over many pages, avoid `stop` between
iterations — state persists across commands by design, and that is the point of
the daemon.
:::
