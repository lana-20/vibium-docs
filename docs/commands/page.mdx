# vibium page

Open, switch between, and close browser pages.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium page new [url]
vibium page switch <index|url>
vibium page close [index]
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Working with pages

```sh
$ vibium page new "https://lana-20.github.io/vibium-docs/fixtures/playground2.html"
New page opened and navigated to https://lana-20.github.io/vibium-docs/fixtures/playground2.html

$ vibium pages
[0] https://lana-20.github.io/vibium-docs/fixtures/playground.html
[1] https://lana-20.github.io/vibium-docs/fixtures/playground2.html

$ vibium page switch 0
Switched to page: B63EE5608617306356FCE6C79559EB81

$ vibium page close 1
Closed page 1
```

`page new` makes the new page active, so commands after it address the new page,
not the one you were on.

:::tip[`page switch` is how you escape a frame]
[`vibium frame`](/docs/commands/frame) switches into an iframe and the switch
persists — and [`go`](/docs/commands/go) does **not** undo it, it navigates the
frame. `page switch 0` resets the context to the top level:

```sh
$ vibium eval "window.top === window.self"
false

$ vibium page switch 0
Switched to page: EEC168825E14551AFA507E0A7ECFE850

$ vibium eval "window.top === window.self"
true
```
:::
