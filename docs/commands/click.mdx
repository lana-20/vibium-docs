# vibium click

Click an element (optionally navigate to URL first).

:::info[Generated reference]
Derived from `vibium help click` at **vibium v26.8.21**. The examples below are the
command's own built-in samples, not captured terminal output. Pages marked
*Verified* instead carry output from a live browser run.
:::

## Synopsis

```
vibium click [url] [selector]
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--timeout` | `timeout` | Max time to wait, e.g. 5s or 5000 (bare number = milliseconds) (default 30s) |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Examples

```sh
vibium click "a"
# Clicks on current page

vibium click https://example.com "a"
# Navigates to URL first, then clicks

vibium click https://example.com "a" --timeout 5s
# Custom timeout (5s, or 5000 for milliseconds)
```
