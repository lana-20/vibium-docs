# vibium download

Set where downloads are saved.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21**, run against this site's own
[playground fixture](pathname:///vibium-docs/fixtures/playground.html) — a fixed page served
from this repo, so the output cannot drift when someone else's markup changes.
Every example is reproducible against that URL exactly as shown.
:::

## Synopsis

```
vibium download dir <path>
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Setting the directory

```sh
$ vibium download dir /tmp/cap
Download directory set to /tmp/cap
```

Set this **before** triggering the download; changing it afterwards does not
move a file already saved.

There is no command to list, wait for, or inspect downloads — `download dir` is
the whole surface. To know a download finished, poll for the file:

```sh
vibium download dir /tmp/cap
vibium click "#download-link"
until [ -s /tmp/cap/sample.txt ]; do sleep 0.2; done
```
