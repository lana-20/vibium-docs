# vibium wait

Wait for an element, URL, text, page load, or JS condition.

:::info[Generated reference]
Derived from `vibium help wait` at **vibium v26.8.21**. The examples below are the
command's own built-in samples, not captured terminal output. Pages marked
*Verified* instead carry output from a live browser run.
:::

## Synopsis

```
vibium wait [selector]
```

## Flags

| Flag | Argument | Description |
| --- | --- | --- |
| `--state` | `string` | State to wait for: attached, visible, hidden (default "attached") |
| `--timeout` | `timeout` | Max time to wait, e.g. 5s or 5000 (bare number = milliseconds) (default 30s) |

Global flags apply as well — see [Global flags](/docs/global-flags).

## Examples

```sh
vibium wait "div.loaded"
# Wait for element to exist in DOM

vibium wait "div.loaded" --state visible
# Wait for element to be visible

vibium wait "div.spinner" --state hidden --timeout 5s
# Wait for spinner to disappear (5s, or 5000 for milliseconds)
```
