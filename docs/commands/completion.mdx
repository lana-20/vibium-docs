# vibium completion

Generate a shell completion script.

:::tip[Verified against a live browser]
Every example on this page is real terminal output captured from **vibium
v26.8.21** on macOS. Paths and ids will differ on your machine.
:::

## Synopsis

```
vibium completion <bash|zsh|fish|powershell>
```

## Flags

This command takes no flags of its own. Global flags apply — see
[Global flags](/docs/global-flags).

## Generating

The shell is required — there is no default:

```sh
$ vibium completion
Error: accepts 1 arg(s), received 0
Usage:
  vibium completion [bash|zsh|fish|powershell] [flags]
```

Each shell emits its own script to stdout:

```sh
$ vibium completion zsh | head -1
#compdef vibium

$ vibium completion bash | head -1
# bash completion for vibium                               -*- shell-script -*-
```

`fish` and `powershell` are also accepted.

## Installing it

```sh
# zsh
vibium completion zsh > "${fpath[1]}/_vibium"

# bash
vibium completion bash > /usr/local/etc/bash_completion.d/vibium
```
