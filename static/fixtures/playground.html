Reference notes

The paragraphs below exist only to make this page taller than the viewport, so that vibium screenshot --full-page has something to capture below the fold.

Vibium assigns element references in document order. Adding markup at the end of a page therefore leaves earlier references unchanged, which is why the interactive section above sits after the form.

Element references do not survive a navigation. After following a link, re-run vibium map before using a reference.

Commands that read the page, such as text and html, accept the same selectors and references as commands that act on it.

The daemon keeps one browser between invocations, so state set by one command is visible to the next.

A scoped map renumbers from the first element inside the scope, rather than filtering a full-page numbering.

Semantic locators match on meaning rather than structure, and generally survive restyling better than CSS selectors do.

This page is served from the documentation repository itself, so its markup changes only when the reference is deliberately updated.
